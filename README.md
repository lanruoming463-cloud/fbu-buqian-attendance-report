## 一、项目背景与目标

纵腾集团（ZT Group）HR 部门面向**海外 FBU（海外仓）**的人力数据报表，覆盖欧洲、美洲、亚太、加拿大、英国等全球区域。本项目的核心是「考勤确认及时性」与「补签流程」两类报表，支持 HR 跨区域、按天/周/月下钻分析，定位未及时确认考勤的员工，并对比历史趋势。

数据口径、区域映射、特殊规则（如捷克区白名单、HRBP 剔除）均固化在 `gen_buqian_stats.py` 中，便于复用与复现。

## 三、报表模块与统计逻辑

报表为单文件 HTML，含三大板块：

### 1. 补签率（正式工 / 劳务工）
- **维度**：大区（三级部门）→ 区域（四级部门）→ 仓（五级部门）→ 组（六级部门）四级下钻。
- **口径**：补签合计 = 已完成 + 审批中；按区域占比图例；各区补签 Top10 员工（可折叠），**Top10 剔除补签事由 = 入职当天 及 备注「客观情况无法打卡」**。
- **剔除大区**：海外销售部、FBU财务部、渠道管理部、LD 法务部（按需求不展示）。
- **剔除区域**：美洲支持HRBP组（不展示，与考勤确认及时率口径一致）。

### 2. 考勤确认及时率（正式工 / 劳务工）—— 主体报表核心
- **维度**：三级部门 = 大区；四级部门 = 区域；五级 = 仓；六级 = 组。
- **时间**：可按天 / 按月 / 按周切换；默认选中最新月份。
- **及时确认率** = (考勤总数 − 未及时确认) ÷ 考勤总数。
- **未及时确认判定（正式工）**：考勤状态 = 异常 且 异常备注不含「迟到 / 早退」（即缺卡类：缺少首打卡 / 末打卡等）；迟到 / 早退视为已及时确认。
- **未及时确认判定（劳务工）**：确认状态 ∉ {已确认, 已复核} 的明细条数（缺卡 / 未确认）。
- **组行角标**：点击组行可展开该组「未及时确认」员工明细（正式工 12 字段含花名册职位 / 职级；劳务工 10 字段含班次 / 首末打卡 / 确认状态 / 异常原因），每组最多 50 条、按考勤日期降序。
- **各区 Top10**：正式工按「未及时确认」排名（含职位列）；劳务工按「未确认数」排名。

### 3. T+1 日更看板（独立模块，不在本生成脚本内）
- 数据源：MCP 人力资源数据市场 + 6/7/8 月正式工考勤导出，每日 10:05 定时任务增量。
- 提供按天 / 按周 / 按月 / 日期范围 / 翻页的全局时间控件联动。
- 注：本主体报表（gen_buqian_stats.py 产出）**不含 8–9 月**，8–9 月仅在独立的 T+1 看板；主体报表数据范围为 **2026-06 / 07 / 10**。

### 区域映射与排序
- 固定大区顺序：**美洲区 → 欧洲区 → 亚太区 → FBU HRBP Dept.**。
- 加拿大区 = 多伦多 + 温哥华 合并，归入美洲区。
- HRBP 各部（××区HRBP部）单独成大区，区域保留「××区HRBP部」原名。

## 四、正式工考勤确认及时率 · 口径演进（截至 2026-10-10）

| 维度 | 规则 |
|---|---|
| **数据范围** | 仅取 **美洲区 / 欧洲区 / 亚太区** 三大区下各区域，以及 **HRBP** 数据 |
| **HRBP 剔除** | 不含 国内HRBP组、美洲支持bp组（= 美洲支持HRBP组）、欧亚支持bp组 |
| **「其他」大区剔除** | 海外销售部、渠道管理部、LD 法务部、FBU技术部、平台业务部、品牌客户部 及 三级部门为空 等无法归属三大区 / HRBP 的记录，整类剔除（共 392 条） |
| **财务部** | FBU财务部 整部剔除 |
| **空四级部门** | 无法归属区域的记录剔除 |
| **捷克区白名单** | 捷克区正式工，首打卡与末打卡**均为空**的缺卡记录（异常备注「缺少首打卡和末打卡」等）视为及时确认，不计入未及时（2026-10-10 起，共改判 136 条，捷克区及时率 96.9% → 99.9%） |
| **职位 / 职级** | 取自 2026-08-24 花名册按工号匹配，未匹配显示「—」 |

> 上述规则仅应用于**正式工考勤确认及时率视图**；劳务工视图与补签率模块未应用「三大区 + HRBP」收窄（如后续需要同口径可另行处理）。

## 六、如何重新生成 / 发布

```bash
# 1) 重新生成报表（读取全部源 Excel，产出 HTML + xlsx，约 7 分钟）
python gen_buqian_stats.py

# 2) 无头 Chrome 探针验证渲染（errs 应为 0）
python _probe39.py

# 3) 部署到妙搭 + 自动同步 GitHub（先改 _deploy3.py 顶部 COMMIT_MSG）
python _deploy3.py

# 4) 仅手动同步 GitHub（可选）
python _github_sync.py "自定义提交说明"
```

数据源路径在 `gen_buqian_stats.py` 顶部集中配置（`FORMAL_ATT_FILES` 正式工、`LABOR_GS_FILES` 劳务工、`BUQIAN_FILES` 补签率、花名册等），新增月份直接在列表追加即可。
