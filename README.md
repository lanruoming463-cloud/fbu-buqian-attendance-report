# fbu-buqian-attendance-report

海外 FBU 补签流程 / 考勤确认 数据报表项目 —— 生成脚本、部署链路、无头验证探针与开发日志。

线上报表（飞书妙搭，需飞书登录）：
https://ztn.larkenterprise.com/page/RgGYm9pJkdaDGKafK8lc5pS1ntf

## 项目结构

| 文件/目录 | 说明 |
|---|---|
| `gen_buqian_stats.py` | 主生成脚本：读取补签流程/劳务工工时/花名册 Excel，产出单文件 HTML 交互报表（补签率、考勤确认及时率×正式工/劳务工、Top10、组角标员工明细）与汇总 Excel |
| `_deploy3.py` | 飞书妙搭部署脚本：浅 fetch → 覆盖 index.html → push sprint/default → release-create → 轮询 |
| `_github_sync.py` | GitHub 同步脚本：收集代码/探针/日志/数据产物，commit + push 到本仓库（发布时联动 + 每日兜底） |
| `_probe*.py` | 无头 Chrome 验证探针：起本地 HTTP 服务 + iframe 加载报表，注入探针取 DOM/计算样式，验证角标、展开、居中、月度联动等交互 |
| `docs/devlog/` | 开发历史日志（按日）：每项需求的实现方案、数据口径、验证结果、踩坑记录 |
| `gen_run*.log` / `_gen_run*.log` / `_deploy3_run*.log` | 生成/部署运行日志 |
| `补签流程_补签统计.html` | 报表产物（约 18MB，内嵌全量数据 JSON） |
| `补签流程_补签统计.xlsx` | 汇总 Excel 产物 |
| `attend_acc_data.json` | 考勤准确率（申诉口径）数据 |

## 报表功能概览

- **补签率**（正式工/劳务工）：大区→区域→仓→组四级下钻，占比图例，各区补签 Top10 员工（可折叠）
- **考勤确认及时率**（正式工/劳务工）：按天/按月/按周切换，区域排序与补签率对齐，组行角标展开未及时确认员工明细（正式工 12 字段含花名册职位/职级；劳务工 10 字段含班次/首末打卡/确认状态/异常原因），各区 Top10
- 顶部共享控件：日期/月份/周切换 + 架构（区域）筛选

## 数据口径要点

- 及时确认 = 确认状态 ∈ {已确认, 已复核}；未及时明细随顶部时间筛选联动，每组最多展示 50 条
- 排除：财务部、空四级部门；补签 Top10 剔除补签事由=入职当天及备注客观无法打卡
- 区域排序固定表（美洲/欧洲/亚太/HRBP），加拿大 = 多伦多+温哥华合并

## 持续同步机制

每次功能发布（妙搭 release）后自动执行 `_github_sync.py` 推送最新代码与文档；
另有每日定时兜底同步。提交信息均附变更说明。
