## 劳务工及时率视图纳入 .wrap 容器（补上轮遗漏）

- 用户截图反馈：考勤确认及时率（劳务工）页面布局仍太宽，要求与补签率一致。
- 复盘上轮（9-17）修复：当时 viewGen 前加了 `<div class="wrap">`、viewGen `</script>` 后加了闭合 `</div>`、attend_block 末尾也加了闭合 `</div>` —— 但这导致 wrap 在 viewAttend **之前**就闭合了（body..viewAttend 净嵌套 = -1），劳务工视图实际仍在 wrap 外全宽渲染。
- 本次修复：删除 viewGen `</script>` 后的那个多余闭合 `</div>`，让 viewGen 和 viewAttend 共用同一个 wrap，由 attend_block 末尾的 `</div>` 统一闭合。
- 嵌套验证：div 深度解析显示 viewFormal/viewGen/viewAttend 均在 depth=3（wrap 内）。
- 无头 Chrome 实测（_probe_width.py，1440px 视口 iframe）：三视图 closest('.wrap') 宽度均为 **1100px**、left 均为 **163px**（居中），viewAttend 与 viewGen 同属一个 wrap（attSameWrapAsGen=true），errors=[]。
- 经验：多视图 HTML 拼接时，改包裹容器必须用「div 深度逐标签追踪」或运行时 closest('.wrap') 实测验证，不能只数开闭标签总量（viewFormal 结尾有历史遗留多余 </div>，浏览器容错导致静态计数失真）。
- 部署：commit 8c94d6324 → release 7686677191779159220（finished，error_logs=[]），数据无变化。
